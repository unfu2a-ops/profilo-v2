portfolio-v2

A personal portfolio website built to showcase my profile, background, and professional experience.

Overview

"portfolio-v2" is a personal front-end portfolio project designed to present my professional identity and make my resume and background more accessible to visitors.

The project focuses on a clean and responsive experience across different screen sizes.

Features

- Responsive design
- Personal portfolio presentation
- Front-end focused architecture

Technologies

- HTML5
- CSS3
- JavaScript
- Git

Getting Started

Installation

Clone the repository:

git clone <repository-url>

Navigate to the project directory:

cd portfolio-v2

Open the main HTML file in your browser to view the website.
